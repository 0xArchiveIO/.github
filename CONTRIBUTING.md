# Contributing

Thanks for helping improve 0xArchive public tooling.

Before opening an issue or pull request:

- Reproduce the behavior with the smallest command, script, or notebook possible.
- Redact API keys, wallet secrets, customer data, and private endpoints.
- Include the client or package version, operating system, and exact route, command, or connection step involved.
- Keep venue language precise: Hyperliquid and Lighter.xyz are top-level venue APIs; HIP-3 lives under Hyperliquid.

For docs and README changes, preserve the first-request path. A new reader should be able to connect, authenticate, and make one successful request before long reference material. The hosted MCP uses OAuth, with no local server installation or 0xArchive API key. Include installation and API-key setup only for interfaces that require them.
